# 🔐 Password Strength Checker

## Overview
A Python-based programmatic logic tool designed to evaluate and verify password complexity against standard enterprise security requirements. This project was developed as part of the DecodeLabs Cyber Security foundational track.

## Core Objectives
* Verify password length and character complexity.
* Implement programmatic logic to filter out weak credentials.
* Demonstrate an understanding of foundational static defense mechanisms.

## Skills Demonstrated
* Python Programming
* Programmatic Logic & Control Flow
* Pattern Recognition
* Security Best Practices (Authentication)
